Entrants write a single funny line, 200 characters or fewer, on any topic they like: a joke, a pun, an observation, a tiny story with a punchline. There is nothing to build, install or upload, so entering takes a minute. A judge model reads the lines two at a time and asks which one is funnier, weighing surprise, tightness, freshness and how cleanly the line reads. The funniest lines climb the board and share the reward.

Our line: "I told my houseplants I was going away for the weekend; they held a meeting and voted to die anyway." (100 characters)

## Run it

```sh
python3 main.py
```
